Where this sits Unit 2 begins in class on 24 Aug — this is the very first tutoring session inside it, so unlike Lessons 1–2 (which consolidated content already taught), this one is genuinely introducing new ground. 'Grandmother's Song' is a short story built almost entirely around a moral lesson delivered through dialogue between generations, so dialogue punctuation is the natural entry point.

Learning objective

By the end of this session, the student will be able to:

  • Correctly punctuate a line of dialogue: quotation marks, capital letter to start the speech, punctuation kept inside the closing quotation mark, and a new line for each new speaker.
  • Explain how the choice of punctuation inside dialogue (short sentences, a dash, an ellipsis) changes how a character comes across — firm, hesitant, interrupted, and so on.
  • Punctuate an unpunctuated passage of dialogue correctly, unaided.

Why this matters for the exam

Dialogue punctuation is one of the most heavily and consistently marked technical accuracy points at this level — get the mechanics automatic now, and it stops costing marks in every single piece of narrative writing for the rest of the year. It also unlocks the more interesting skill of characterisation through dialogue, which is exactly what 'Grandmother's Song' is built around, and which resurfaces in Unit 5 (script writing) and beyond.

A note on the text used

This session uses an original short dialogue scene, "The Last Ripe Mango," written to mirror 'Grandmother's Song' in structure — an intergenerational exchange where an older relative teaches a lesson through a small, concrete moment, told mostly through dialogue. Once you have the actual Learner's Book / Workbook text, swap it in directly; the punctuation-hunting and characterisation activities work identically on the real story.

Likely confusion point Where the comma or full stop goes relative to the closing quotation mark is the single most common error at this level — students often write "Stop", she said. instead of "Stop," she said. Drill this specifically; see the script for a simple physical rule ("the comma lives inside the house").
Likely confusion point Forgetting to start a new line for each new speaker is common when students are excited to get dialogue down quickly. Frame it as a reader-courtesy rule: "if you don't start a new line, your reader can't tell who's talking without stopping to work it out."
